# ТРИЗУБ // Киев-Неон 2094

Художественный портал альтернативной истории. Внешний контур Гетьманату: шестнадцать разделов, интерактивная карта мира, досье, лавка mesh.

Это вымысел. Память о Чернобыльской катастрофе 1986 года в мире портала не отменена и не превращена в аттракцион.

## Запуск

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Откройте `/`. Язык оболочки — русский.

## Разделы

Портал, Хроники, Гетьманат, Персонажи, Карта, Альянсы, Киев, Технологии, Корпорации, Зона, Орбита, Культура, Лента, Кодекс, Магазин, Терминал.

## Источники геометрии и знаков

- Контуры стран: [world-atlas](https://github.com/topojson/world-atlas) / Natural Earth, собраны в `data/map.json`. Осколки Разлома — авторское деление.
- Флаги современных государств: [Flag Icons](https://github.com/lipis/flag-icons), MIT.
- Шрифты: Unbounded, Manrope, JetBrains Mono, Russo One, Philosopher — SIL Open Font License, файлы в `assets/fonts`.
